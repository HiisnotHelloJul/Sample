# Distance Calculator

## This tool measures the space between two or more points. . It can measure straight lines on a map, driving routes between cities, or math coordinates using numbers. Using a Math Library, this code can work properly and efficiently.

### How to run this program:
This program allows you to enter the values of the given variables to be calculated by the Distance Calculator. After the calculation, it will be printed and shown to the user.

### Input Needed:
x1 = int(input ("x1: "))

x2 = int(input ("x2: "))

y1 = int(input ("y1: "))

y2 = int(input ("y2: "))

### Sample Output:
x1: 2

x2: 7

y1: 3

y2: 8

The distance between the two points is: 7.07
